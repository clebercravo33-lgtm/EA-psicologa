# Agenda Elayne — PWA

Arquivos para publicar no GitHub Pages:

- `index.html` — aplicativo
- `manifest.webmanifest` — configuração do PWA
- `sw.js` — service worker/cache

No GitHub, coloque os três arquivos na mesma pasta (normalmente a raiz do repositório) e ative o **GitHub Pages**.

Importante: PWA/service worker funciona quando o site é servido por HTTPS, como no GitHub Pages.
